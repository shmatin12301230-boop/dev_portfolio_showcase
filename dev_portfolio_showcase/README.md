# dev_portfolio_showcase

Набор сайта с пятью рабочими проектными направлениями:

- `index.html` - главная страница портфолио
- `projects/neuroflow-bot` - бот / автоматизация
- `projects/signalboard-dashboard` - SaaS-дашборд
- `projects/atelier-launch` - премиальный лендинг
- `projects/relaydesk-portal` - клиентский портал / CRM
- `projects/lunex-storefront` - e-commerce / продуктовая витрина

Как использовать:

1. Открой `index.html` в браузере.
2. При желании подкорректируй заголовки, цифры и офферы под свои цели.
3. Используй как рабочую витрину услуг и технологической экспертизы.

Почему такая подача важна:

Проекты собраны так, чтобы быстро показать качество интерфейсов, продуктовую
логику и готовность к реальной работе с заказчиком.
